# Unit 1: Introduction to Data Structures & Arrays

**Course:** IC-307D | Data Structures and Algorithms Lab  
**Course Outcome:** CO1  
**Language:** Python 3.10+

## Basic requirements
- Implement 1D and 2D array operations: insert, delete, search, rotate.
- Sparse matrix representation (triple format) and basic operations.

## Application requirements
- Build a menu-driven Matrix Calculator supporting addition, multiplication, transpose, and determinant for small matrices.
- Analyze space optimization using sparse representation.
