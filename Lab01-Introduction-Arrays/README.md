# Unit 1: Introduction to Data Structures & Arrays

**Course:** IC-307D | Data Structures and Algorithms Lab  
**Course Outcome:** CO1

## Basic requirements
Implement 1D and 2D array operations (insert, delete, search, rotate). Sparse matrix representation (triple format) and basic operations.

## Application / analysis requirements
Build a menu-driven Matrix Calculator (add, multiply, transpose, determinant for small matrices). Analyze space optimization using sparse representation.
