This directory contains full, standalone implementations of the four End-Semester Capstone Projects mandated in the IC-307D syllabus:

1. [**Project 01: Mini Database Engine**](./Project01-Mini-Database-Engine/README.md)
   - Combines Arrays, Linked Lists, Hash Tables, and BST Indexing.
   - Supports CRUD operations with Primary Key indexing and Secondary attribute range queries.
2. [**Project 02: Hospital Management System**](./Project02-Hospital-Management/README.md)
   - Priority Queue (Min-Heap) for Emergency Room patient triage.
   - Stack for Doctor consultation history & undo.
   - N-ary Tree for clinical department organizational hierarchy.
   - Graph for epidemic contact tracing and patient relationships.
3. [**Project 03: E-Commerce Backend Simulator**](./Project03-ECommerce-Backend-Simulator/README.md)
   - BST Product Catalog with SKU indexing.
   - Shopping Cart with LIFO item undo stack.
   - FIFO Order processing warehouse queue.
   - Co-purchase Recommendation Graph.
4. [**Project 04: Pathfinding Visualizer**](./Project04-Pathfinding-Visualizer/README.md)
   - Grid-based pathfinding engine comparing BFS, DFS, and Dijkstra.
   - ASCII visual matrix rendering with node expansion benchmark metrics.
