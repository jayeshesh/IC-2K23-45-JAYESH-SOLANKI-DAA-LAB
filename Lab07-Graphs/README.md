# Unit 7: Graphs

**Course:** IC-307D | Data Structures and Algorithms Lab  
**Course Outcome:** CO3

## Basic requirements
Graph representations (Adjacency Matrix + Adjacency List); BFS and DFS (recursive + iterative); weighted graph + basic shortest path (Dijkstra optional for strong students).

## Application / analysis requirements
Social Network/Friendship Graph (friends of friends, connected components); Maze Solver or Shortest Path Navigator (grid as graph); Course Prerequisite Tracker (topological sort bonus); Route planner or network connectivity analyzer.
