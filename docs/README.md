# Documentation

This folder holds the guide's central documentation deliverables.

- `diagrams/`: draw.io or PlantUML diagrams
- `algorithm-flowcharts/`: algorithm flowcharts
- `complexity-analysis.pdf`: complexity analysis
- `final-report.pdf`: final lab report
- `presentation.pdf`: presentation

The PDFs will be generated after actual implementation and test evidence exists.

See [program README template](./PROGRAM-README-TEMPLATE.md), [complexity outline](./complexity-analysis-outline.md), [final report outline](./final-report-outline.md), and [presentation outline](./presentation-outline.md).
