# Unit 2: Sorting & Searching Algorithms

**Course:** IC-307D | Data Structures and Algorithms Lab  
**Course Outcome:** CO2

## Basic requirements
Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quick Sort, Heap Sort, Radix Sort, Binary Search.

## Application / analysis requirements
Compare all sorting algorithms by empirical timing across input sizes and random, sorted, and reverse-sorted data. Generate graphs using matplotlib via Python or export data. Student Record Manager: sort/search by roll number, name, and marks and provide a comparative performance report. Search Engine Simulator: dictionary using binary search + hashing; handle collisions using Separate Chaining + Linear Probing.
